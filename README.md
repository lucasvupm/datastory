# 共同班表

兩個人各自把班表丟進去，就變成一份看得懂的共同班表：哪幾天一起休假、哪幾個晚上都有空、誰上什麼班。

不用註冊、不用後端、沒有任何相依套件，整個 App 就是一個 HTML 檔。

## 為什麼不是「再一個行事曆 App」

班表最麻煩的不是畫月曆，是**每個人的班表長得都不一樣**。所以這個 App 的重點在兩件事：

**它會問你。** 讀到看不懂的東西不會亂猜，也不會直接壞掉，而是變成一張問題卡：

- 「`G2` 是什麼班？」——猜一個時間給你改，旁邊附上它出現在哪幾天
- 「`1` 我猜是早班，對嗎？」——數字代號每間公司不一樣，一定先確認
- 「`大夜` 寫在 10/5，是指 10/5 去上班，還是 10/4 晚上去、10/5 早上下班？」——選錯會讓共同空檔整個差一天
- 「你貼的好像是 11 月的班表，要切過去嗎？」
- 「10/15 有兩筆資料（早、休），要用哪個？」
- 「有 12 天沒有資料，是休假還是班表只給到這裡？」

**它會記住。** 回答過的班別存進字典，下個月貼新班表就不會再問。字典可以匯出成一個檔案傳給另一半匯入，兩邊就同步了。

## 直接傳照片

班表多半是拍來的或截圖來的，所以可以直接把圖丟進去 —— 拍照、選檔、拖曳、或 Ctrl+V 貼上都行。

讀完**不會直接套用**，而是先轉成文字填回輸入框，讓你看得到它讀到什麼、也改得動。之後走的是跟手動貼上一模一樣的流程，所以「不認得的代號」那些問題照問。

醫院和賣場的班表照片通常是**整組人**的，所以讀完會多問一句：

> 照片裡有 8 個人的班，哪一個是你？
> 　王小明（31 天）　李小美（30 天）　…

Claude 讀的時候哪裡模糊、哪裡被遮住，會寫在備註裡一起顯示出來，不會默默猜過去。

圖片在送出前會先在你的裝置上縮到長邊 1600px 再上傳，4G 也不會等太久。這個功能需要 claude.ai 的 `sample` 能力，所以**只有發佈成 Artifact 的版本才有**；單檔版和 GitHub Pages 版會自動隱藏這個按鈕，提示你改用文字貼上。

## 看得懂的格式

貼上去之前不用整理，讀不出來的地方它會問。全形、tab、從 Excel 直接複製都可以。

```
10/1 早班            ← 一行一天
10/2 休

一 二 三 四 五 六 日    ← 表格：星期列（會自動略過）
1  2  3  4  5  6  7     日期一列
早 早 休 休 中 中 早     班別一列

早班：1,3,5,7,9      ← 班別對日期，支援 10-13 這種範圍
休：2,4,6

10/5 08:00-17:00     ← 直接寫時間，不用教它
早 早 休 休 中 ...    ← 只有代號，從 1 號開始排（可以改起始日）
```

內建認得 `早 / 中 / 小夜 / 大夜 / 常日 / 開店 / 關店 / 全天 / 半天 / 休 / 例 / 特休 / 國定 / 病 / 事 / 補`，
以及 `D E N A B C G1 O OFF X R` 這類英文代號。

## 算出什麼

- **月曆**：每一格下面是一條 0–24 點的微型時間軸，兩條色帶是兩個人的班，金色那條是兩人都有空的時段
- **一起休假**：連續的共同休假會被串成一段（「10/8–10/9 兩天連休」）
- **有空檔的時段**：清醒時間扣掉上班、通勤緩衝、大夜下班後的補眠，剩下的交集；短於 2 小時的不算
- **匯出**：PNG 圖片（直接傳給對方）、`.ics` 行事曆（Google / iPhone 都能匯入）、純文字（貼 LINE）

通勤時間、補眠時數、清醒時段、最短空檔都可以在「設定」調。

## 怎麼跑

```bash
npm test      # 45 個測試，涵蓋解析、詢問、合併、匯出、照片結果處理
npm run build # 產生 dist/index.html（單檔）與 dist/artifact.html
npm run serve # http://localhost:5173 開發用
```

`dist/index.html` 是單一檔案，雙擊就能開，也可以丟上 GitHub Pages 或直接傳給別人。

## 資料存在哪

- **一般情況**：`localStorage`，只留在那台裝置，不會上傳到任何地方
- **發佈成 claude.ai Artifact 時**：改用共用資料庫，兩個人開同一個連結看到同一份班表（對方需要有 Contributor 以上的權限才能編輯）。權限不夠時會自動退回單機模式，功能照常。

兩種情況都可以用「匯出設定檔 / 匯入設定檔」手動同步。

## 檔案

```
src/core/dict.js      班別字典、代號正規化、沒見過的代號怎麼猜
src/core/parse.js     五種版型的解析器，各自給信心分數，挑最高的
src/core/clarify.js   把「我不確定」變成問題卡；回答寫回字典
src/core/merge.js     合併兩人班表、共同休假、共同空檔
src/core/export.js    ICS / 純文字 / 備份
src/ui/photo.js       照片縮圖、給 Claude 的提示、回傳結果的防呆
src/ui/               狀態、畫面、PNG 繪製、儲存轉接層
scripts/build.mjs     把模組串成單一 HTML
```

核心（`src/core/`）沒有碰 DOM，所以測試直接用 `node --test` 跑。
